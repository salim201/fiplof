# Structure du module OperationsSubsequentes

## Description
Le module OperationsSubsequentes gère toutes les opérations qui peuvent survenir après l'émission initiale d'un certificat foncier, incluant les transferts, les mutations et autres actes juridiques.

## Fichiers principaux

### Gestion des actes
- Scripts de gestion des différents types d'actes notariés
- Formulaires de saisie des actes
- Validation et enregistrement des actes

### Gestion des transferts
- Scripts de gestion des transferts de propriété
- Calcul des droits et taxes
- Mise à jour des registres

### Gestion des mutations
- Scripts de gestion des mutations
- Suivi des changements de propriété
- Historique des mutations

## Fonctionnalités principales

### 1. Gestion des actes
- Création et modification d'actes
- Classification des types d'actes
- Archivage des documents

### 2. Transferts de propriété
- Transferts entre personnes physiques
- Transferts vers personnes morales
- Gestion des quotes-parts

### 3. Mutations
- Mutations par décès
- Mutations par donation
- Mutations judiciaires

### 4. Suivi juridique
- Validation des actes
- Enregistrement légal
- Publication des actes

## Dépendances
- Module Certificat pour la liaison avec les certificats existants
- Module Configuration pour les paramètres juridiques
- Base de données pour la persistance des données
